# وقتي – منظّم وقت الطالب
1. اعمل حساب مجاني على github.com ثم New repository (اسمه waqti).
2. ارفع كل محتويات هذا المجلد (مع مجلد .github) عبر Add file > Upload files.
3. افتح تبويب Actions وانتظر 5-10 دقايق حتى يخضر Build apps.
4. افتح آخر تشغيل وحمّل من Artifacts:
   - waqti-android-apk : ملف APK للأندرويد
   - waqti-windows-installer : ملف EXE لتثبيته على ويندوز
